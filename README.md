<h3 align="center">🚀 I build the backend systems most developers avoid — auth, concurrency, and data integrity that hold up under real users and real attackers.</h3>

<p align="center">
Most tutorials stop at the happy path. I focus on what happens when two requests race for the same row, when a token needs to be revoked mid-session, or when someone tries the same login 500 times in a minute. My work is Django/DRF backends built to fail loudly in code review, not silently in production.
</p>

---

### ⚡ What I actually do

- 🔐 **Secure auth systems** — JWT with rotation & blacklisting, OAuth2 (Google/GitHub/LinkedIn/Facebook), TOTP-based 2FA with hashed backup codes, OTP email verification, brute-force lockout, and session/device tracking — designed around concurrency and abuse cases, not just the happy path.
- 🏗️ **Backend architecture that survives contact with production** — service-layer separation, atomic transactions, row-level locking (`select_for_update`), audit logging, and GDPR-compliant data lifecycles.
- 🎨 **Full-stack delivery** — Django REST APIs paired with React front-ends, shipped end-to-end, not just API design in isolation.
- 🔬 **Research background** — MSc Computer Science, focused on Privacy-Preserving Federated Learning and Medical AI.
- 🌱 **Currently deepening** — CI/CD pipelines and container orchestration, to take Docker/AWS from "I use these" to "I deploy and scale with these."
